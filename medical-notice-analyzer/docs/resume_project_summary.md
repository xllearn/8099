# Resume Project Summary

## Working Title

MedNoticeAI: Medical Procurement Notice AI Analysis and Report Generation Platform

## One-Sentence Summary

An incremental FastAPI-based system for selecting public medical procurement notices, building evidence packs, generating structured AI analysis reports, checking quality, and exporting Word reports.

## Current Resume Direction

- Backend engineering around long-running AI report jobs.
- LLM workflow orchestration with a migration path from Dify to a local workflow engine.
- Evidence reliability and quality gates for formal report output.
- Scoped long-term memory that guides style without becoming current facts.
- Repeatable quality evaluation with public and synthetic fixtures.

## Stage Notes

P0-1 begins by adding workflow run persistence and backend metadata around the existing Dify flow without changing user-visible report generation results.
